# 🎧 Moodify AI — Frontend

This is the React + Vite frontend for **Moodify AI**, featuring real-time facial expression recognition using `@mediapipe/tasks-vision` and an interactive glassmorphic music player UI.

For complete documentation on the full-stack project, setup instructions, backend API, and features, please check the [Root README.md](../README.md).

## 🚀 Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
